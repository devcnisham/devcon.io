# DevCon studio redesign

User rejected the prior layout and supplied a white security-agent reference. They explicitly declined the portrait image, so the new visual uses an original code-native project schematic instead.

## Direction
White #FFFFFF, ink #1B1B1E, mist #F8F8F7, orange #F36E36, dark orange #B94419, secondary gray #727276. Inter Tight for display, DM Sans for body, IBM Plex Mono for utility labels. Reference-inspired three-column hero: proposition, animated project agent, and concise activity/status rail. No inherited split hero, orbital particle field, or warm color layer.

## Content and interaction
The hero visual connects an idea or repo to focused steps, contextual prompts, and explained omissions. The interactive workspace includes side-project, university, and hackathon examples; every step opens its own contextual coding prompt with working copy feedback. Sample plans are explicitly illustrative. No invented users, testimonials, partner logos, or measured performance claims.

## Motion and access
Animated SVG signal paths, sequential agent activity, restrained floating artifacts, and scroll reveals. Pause control and reduced-motion handling. Mobile navigation and tab keyboard controls, prompt focus return, native FAQ controls, and visible focus styles.

## Scope
Standalone landing page using existing app and docs destinations. No portrait, no generated asset, and no modification of the private Next.js application.
